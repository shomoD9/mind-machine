## Question

Given [Load-bearing failure](01-load-bearing-failure.md) and [Why tools lose them](02-why-tools-lose-them.md), which single failure is the spine of the pitch?

The other failures have to be classified: a consequence of the spine, a separate job inside the same product, or outside this pitch. The pitch gets one spine. This ticket is a conversation. The human names the spine. The agent does not answer for them.

## Answer

The spine is goal neglect: intentions the person has already formed stop governing what they do, under the load of many open projects. Recall can survive. Many projects and context switching amplify the failure. Organizing thoughts is compensation. The inability to stay on one thing is downstream. Tool upkeep that outruns benefit is how existing systems lose this person as that load grows. It is not a second spine.
